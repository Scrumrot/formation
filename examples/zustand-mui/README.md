# Golden project: zustand + MUI

Forms generated by `@formation/cli`, then held to the standard a real app would hold them
to. This is layer 3 of the testing plan (docs/plan.md §10): snapshots prove output is
_stable_, this proves it _compiles and works_.

```bash
pnpm golden          # from the repo root: build, regenerate, typecheck, test

pnpm generate        # from here: rerun the CLI over schemas/ for each MUI major
pnpm typecheck       # tsc against @mui/material 9, then against 7
pnpm test            # render and drive every form, on 9 and then on 7
```

| Schema                  | Input kind  | What it exercises                                                                     |
| ----------------------- | ----------- | ------------------------------------------------------------------------------------- |
| `schemas/profile.ts`    | Zod module  | `z.date()`, a refinement, custom messages, lists in lists, unions (one as a list row) |
| `schemas/order.json`    | JSON Schema | `$ref`, `allOf`, titled and numeric enums, bounds, defaults, a record                 |
| `schemas/petstore.yaml` | OpenAPI 3.0 | `--select`, `nullable: true`, one-branch `allOf`, a required union by `discriminator` |
| `schemas/consent.json`  | JSON Schema | a form with one control kind, so unused runtime must not be emitted                   |

## How the two MUI majors are checked

`@mui/material` 9 is installed normally and 7 beside it under the alias `mui7`. Each major
has its own generated tree (`src/generated/mui9`, `src/generated/mui7`), its own tsconfig
that resolves `@mui/material` to that major's declarations, and its own vitest config that
resolves it to that major's runtime. One spec file runs under both, and its first test
asserts which MUI it is actually running against.

The typecheck runs under `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`
and `noUnusedLocals`, because generated code lands in projects with all of them on.

## Do not hand-edit `src/generated`

It is CLI output, regenerated wholesale with `--force`. To change it, change the generator
and run `pnpm generate`; the diff is the review.
